# About Luweh
LUWEH adalah platform berbasis aplikasi web yang dirancang untuk mengatasi permasalahan sampah makanan atau food waste dengan menghubungkan pelaku usaha makanan dan minuman (seperti restoran, hotel, toko roti, dan kafe) dengan konsumen.

## Cara Menjalankan
1. Clone repositori ini lalu masuk ke foldernya.
2. Jalankan `composer install`.
3. Salin `.env.example` menjadi `.env`, lalu jalankan `php artisan key:generate`.
4. Atur koneksi database di `.env`.
5. Jalankan `php artisan migrate`.
6. Jalankan `php artisan serve` di terminal.
7. Buka `http://127.0.0.1:8000` di browser.
